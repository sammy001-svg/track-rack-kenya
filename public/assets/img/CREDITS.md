## Replacing these

These are stand-ins until Tack Rack's own photography is available.

**Product photographs** are managed in the admin console (Products → edit →
Photographs). Once a product has its own image it overrides the category fallback
automatically — nothing here needs touching.

**Site-wide images** are files on disk. Replace them in place, keeping the same
filename and aspect ratio, and regenerate the `.webp` alongside:

| File | Aspect | Appears on |
|---|---|---|
| `hero-leather.jpg` | 4:5 portrait | Homepage hero panel |
| `heritage.jpg` | 16:9 | Heritage page banner |
| `pillar-rider.jpg` | 4:5 portrait | Homepage curation grid — Rider |
| `pillar-horse.jpg` | 4:5 portrait | Homepage curation grid — Horse |
| `pillar-stable.jpg` | 4:5 portrait | Homepage curation grid — Stable |
| `service-fitting.jpg` | 3:2 | Services index — saddle fitting |
| `service-repairs.jpg` | 3:2 | Services index — workshop repairs |
| `og-default.jpg` | 1200x630 | Preview card when a link is shared |
| `placeholder-*.jpg` | 4:5 portrait | Products with no photograph yet |

`favicon.svg` is the Tack Rack mark, drawn rather than photographed, and is not a
placeholder.
