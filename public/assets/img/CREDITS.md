## Replacing these

These are stand-ins until Tack Rack's own photography is available.

**Product photographs** are managed in the admin console (Products → edit →
Photographs). Once a product has its own image it overrides the category fallback
automatically — nothing here needs touching.

**Site-wide images** are files on disk. Replace them in place, keeping the same
filename and aspect ratio, and regenerate the `.webp` alongside:

| File | Aspect | Appears on |

| `hero-leather.jpg` | 4:5 portrait | Homepage hero panel |

## Logo and icons

`logo.png`, `logo-light.png`, `og-logo.jpg`, `favicon.ico`, `apple-touch-icon.png`
and `icon-*.png` are all generated from `logo-source.png` by:

```
php bin/make-logo.php
```

That script knocks the white background out to transparency, produces an ink version
for light surfaces and a bone version for dark ones, crops the horse-head mark for the
favicons and renders them on the brand ink so they stay legible at 16px.

To change the logo, replace `logo-source.png` with a higher-resolution file and run the
script again. Nothing else needs editing. The current source is 414x190, taken from the
previous website; a larger original will sharpen every derivative.

## Share card

`og-default.jpg` and `og-default.webp` are **not** stock. The card is generated by

```
php bin/make-og-image.php
```

from Tack Rack’s own logo and their own photograph of the Thorowgood saddle
(`uploads/products/thorowgood-leather-saddle-01.jpg`). It is set as `seo_share_image`,
so it is what appears when any page without a picture of its own is shared.

The two typefaces it draws with, Fraunces and Inter, are both under the SIL Open Font
License. They are fetched into `build/fonts/` on demand and are not committed.
